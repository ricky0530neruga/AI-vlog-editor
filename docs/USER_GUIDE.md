# AI Vlog Maker v1.5 使用手冊

## 工作流程

1. 從 **素材與 AI 分析** 加入影片或照片，選擇輸出資料夾及 AI 模型。
2. 點 **開始掃描與 AI 分析**；既有資料可按 **沿用既有分析**，不需再跑 Ollama。
3. 到 **剪輯工作台** 檢視候選鏡頭，加入片單後在右側表格拖曳排序。
4. 在 **預覽／裁切** 視窗中觀看來源片段，設定 In、Out 後套用。
5. 選擇音樂／轉場／現場聲音，點 **輸出 MP4**；在 **執行紀錄** 追蹤進度。

## 操作注意

- Ctrl+Z / Ctrl+Y 可復原／重做本次編輯的片單變動。
- 下方時間軸目前是鏡頭選取與視覺化概覽；**還不能直接拖邊界精修**。
- 目前沒有整部電影級即時播放；全片預覽是後續功能。
- 原始照片／影片不會因輸出被修改。
- 手動裁切會被鎖定，但總片長仍可能因交叉淡化減少。
- 重選 AI 推薦片單可能覆寫人工編輯；請先備份工作區。

## 素材與工作區

輸出工作區維持 V1.4 的規則，包含 `index.sqlite`、`ui_selected_v441.json`、暫存剪輯檔與完成影片。
**不要**把已有資料庫與選片 JSON 移到這個新專案的 `config/`：該資料夾只放程式安裝設定。
