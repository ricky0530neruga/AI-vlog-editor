# AI Vlog Maker v1.5 — PySide6 使用手冊

這是 **v1.5 Alpha** 的工作流程，保留 v1.4 的 AI 分析、選片、裁切與 FFmpeg 輸出方式。`vlog_qt.py` 是新的 Qt 主視窗；舊版 `vlog_gui.py` 仍可作為退路使用。

## 第一次使用

1. 執行 `setup_windows.bat`，建立 `.venv`，安裝 PySide6、python-vlc、PyInstaller。
2. 檢查 `tools/ffmpeg.exe` 與 `tools/ffprobe.exe`，或確認 FFmpeg 已加入 PATH。
3. 安裝與 Python 位元數相符的 **VLC 64-bit**，啟動 Ollama 並確認所需模型存在。
4. 執行 `check_env.bat`，再執行 `start_gui.bat`。

## 新版 GUI 導覽

- **01 素材與 AI 分析**：加入素材、選擇輸出路徑、選模型與模式、執行掃描分析。測試模式會限制掃描數量。
- **02 剪輯工作台**：左側是 AI 候選，右側是已選片單。選擇候選後按「加入片單」，或使用「AI 重選」建立自動片單。
- **03 執行紀錄**：顯示 CLI 分析與 FFmpeg 渲染進度，並能停止作業。

## 影片裁切與片單

- 選擇一段影片後，雙擊該影片或按「▶ 預覽／裁切」。
- 在 PySide6 裁切視窗內使用 VLC 播放、暫停、跳轉，並輸入 In／Out（例如 `00:12.000` 到 `00:18.000`）。
- 點「套用裁切並加入片單」。原片不會修改，片單記錄會保存在原工作區。
- 右側片單可透過拖曳整列、上移／下移調整輸出順序。下方圖形時間軸可點選定位鏡頭。
- `Ctrl+Z` 和 `Ctrl+Y` 可在**本次程式運行期間**撤銷／重做片單操作。關閉應用程式後，持久保存的是最新片單，不保存 Undo 歷史。
- 照片沒有 In／Out 裁切，照片時間由原本的自動片長演算法決定。

## 輸出

設定目標片長（秒）、最低 AI 分數、背景音樂、交叉淡化、保留現場聲與節拍對齊，按「輸出 MP4」。沿用 v1.4 的 FFmpeg 渲染引擎，輸出檔仍是 `Travel_Vlog_Final_V43.mp4`。

> 目前的圖形時間軸屬於 **v1.5 第一階段**：可選取鏡頭、看出順序和長度；精確 In／Out 改動使用裁切視窗。尚未支援從時間軸邊緣直接拖曳裁切、整片低畫質預覽或多軌特效，不應誤認為已完成。

## 相容及退路

- 使用 v1.4 原有的 `AI_Vlog_<hash>` 工作區、`index.sqlite`、`ui_selected_v441.json`；不需要重新分析既有素材。
- 可用 `start_legacy.bat` 啟動 Tkinter v1.4 GUI 做比較。
- 不要在 GUI 以外同時修改相同工作區內的片單 JSON，以免發生版本覆蓋。
- 若更改來源媒體的位置，使用原本的工作區重新掃描時可能使部分候選 ID 失效；程式會備份片單並保留有效項。
