# CHANGELOG

## 1.6.0-experimental — 2026-10-28

- 新增現況架構審查、技術債與分階段實作計畫。
- 新增唯讀 SHA256 素材清單、人工標註、隔離舊版掃描/分析、快取重播及 JSON/Markdown 比較工具。
- 新增 opt-in FFmpeg 場景切分、精確候選區間、多代表影格與技術品質風險；不因單張低品質淘汰場景。
- 新增保守多影格 dHash 近似去重；缺少資訊保留不確定性。
- 新增嚴格多維 JSON 驗證、模型 digest/Prompt/schema 版本、獨立續跑 SQLite sidecar、原始回應與錯誤保存。
- 新增可解釋、多樣性及去重推薦，保留既有 plan/裁切，輸出片長不足資訊；敘事相關性留空。
- Qt 有人工片單時另存 AI 預覽，保護原順序與裁切；新多維引擎透過 CLI opt-in 使用。
- 既有 SQLite、JSON、GUI 與 renderer 保留；不強制重建舊快取、不升級依賴。
- 新增真實 FFmpeg 場景測試、舊庫相容、快取/驗證、決定性及人工裁切保護測試。

沒有人工標註的品質改善仍為尚未評估；不將候選減少或 proxy 去重率當作成片品質提升。
