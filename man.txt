AI Vlog Maker v1.4.0 — 繁體中文操作手冊
=========================================

【這版新增什麼】
1. 在「② 挑選片段 → 剪輯輸出」頁，選取左邊候選影片或右邊已選影片。
2. 點「▶ 預覽／裁切」：開啟內嵌 VLC 播放器，可播放、暫停、拖動進度條、調音量。
3. 可按「設為目前時間」或直接輸入開始 In／結束 Out。
4. 按「套用裁切並加入片單」，原片範圍會儲存為手動鎖定，片單長度旁標示 ✂。
5. 依原本方式排列鏡頭，然後按「② 按選定片單開始剪輯輸出 MP4」。
6. 只調整片段不需要再跑 Ollama；原始照片影片永遠只讀取。

【安裝 / 手動操作】
原本需要：Windows 10/11、Python 3.10+、FFmpeg / FFprobe、Ollama / gemma3 視覺模型。
新增播放器需要：
  A. 安裝「64-bit VLC Media Player」（須包含 libvlc.dll）：https://www.videolan.org/vlc/
     或 PowerShell：winget install --id VideoLAN.VLC --exact
  B. 在目前執行 GUI 的 Python 環境安裝：py -m pip install python-vlc
  C. 重新開啟 Antigravity / PowerShell，在專案根目錄執行：py app.py
     如果 VLC 安裝在非預設資料夾，可設定環境變數 VLC_DIR 指向有 libvlc.dll 的資料夾。

【重要：別誤開到舊版 EXE】
舊 start_gui.bat 只要看到 dist\AI_Vlog_Maker\AI_Vlog_Maker.exe 就會優先開啟該 EXE。
所以更新 Python 原始碼後，測試新功能時請用「py app.py」；
確認正常後，再執行新版 build_windows.bat 重新打包 Windows EXE。
新版 auto_setup.ps1 可在有網路、可使用 winget 的 Windows 電腦嘗試安裝 VLC。
EXE 不包含 VLC 的 DLL 與 plugins；移到其他電腦仍須另外安裝 VLC。

【精確 In / Out 裁切】
例：影片原長 30 秒，設定 In=00:12.000、Out=00:18.000，保留片長就是 6 秒。
時間格式可輸入 12、12.5、00:12.500 或 00:01:12.500。
最短裁切範圍為 0.5 秒，結束時間不得超過原影片長度。
按「▶ 只播放裁切範圍」可反覆檢查 In-Out（需 VLC 安裝正常）。
若 VLC 尚未安裝，視窗會顯示具體錯誤，仍可用數字輸入裁切時間並保存。
照片暫不支援 In/Out，照片仍沿用原本的顯示秒數。

【剪輯時長規則】
- 手動鎖定的 In/Out 不會因目標總長度、AI 重新分配或音樂節奏對齊而被改掉。
- 未鎖定鏡頭仍依原版演算法自動調整秒數。
- 交叉淡化會重疊前後片段，因此「最終影片總長」可能小於鏡頭秒數總和。
- 如果所有手動片段只有 20 秒，目標輸出設 180 秒也不會擅自重複或拉長素材。
- 現有輸出檔名沿用 Travel_Vlog_Final_V43.mp4，GUI 覆蓋前會先詢問。

【保留的舊資料】
工作區、index.sqlite、Ollama 評分和舊的 ui_selected_v441.json 均不必清除。
手動裁切會寫入該 JSON 的 trims 欄位，按候選鏡頭 ID 保存；
舊 JSON 只有 candidate_ids 沒有 trims 仍可正常讀取。
不同來源清單可能建立不同工作區；可在 GUI 選擇既有工作區恢復。
原始素材不會被刪除、複製覆蓋或直接修改。

【增量安裝與 Git】
- 先從 stable v1.3 建立開發分支，例如 git switch -c feature/v1.4-preview-trim。
- 將增量包中的檔案放到原本專案根目錄（請先查看 diff，尤其是已自行修改過 GUI 文案的情況）。
- 新增 video_preview.py；替換 vlog_gui.py、vlog_maker.py、cinematic_editor.py、
  build_windows.bat、auto_setup.ps1、man.txt；新增 CHANGELOG_V1_4.txt。
- 使用 py app.py 測試，確認剪輯正確後再 Commit / Push 到 feature 分支。
- tests/ 內提供裁切、影片輸出與 GUI 儲存自動測試。

【已驗證 / 未驗證】
已驗證：Python 語法、手動 In-Out 邏輯、SQLite 片單儲存、Linux 虛擬 GUI 操作、
FFmpeg 輸出選定時間的實際影片，以及舊快取與既有分析流程的相容性。
尚未在 Windows 實機確認：VLC 嵌入播放器、Windows HEVC/4K 解碼、PyInstaller EXE 發行。
若有播放相容性問題，請先提供 GUI 錯誤訊息，以及 VLC / python-vlc 版本。
